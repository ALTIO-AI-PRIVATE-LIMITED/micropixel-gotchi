# DevCon Wall

Nine Gotchis in a 3x3 grid play one Devcon 8 India animation together. Each
Gotchi shows its own 296x240 tile of an 888x720 canvas (the Gotchi panel is
296x240 landscape, see `platform/boards/cheeko-gotchi/board_config.hpp`).

## Setup at the booth

1. Join all nine Gotchis to the same Wi-Fi (a small travel router is best;
   phone hotspots often cap clients below 9). The network must pass UDP
   broadcast (most booth/home routers do; guest networks with client
   isolation do not).
2. Start DevCon Wall on each. First start asks for the spot: 1-9, row by row
   from the top left, as seen from the front. Spot 5 (centre) is the leader.
3. Tap any screen to see its spot map and sync dot for 6 s: green synced,
   amber looking for the leader, red no Wi-Fi. Hold 1.5 s or press BOOT to
   pick the spot again.

## How sync works

The leader broadcasts its show clock (UDP port 47805) five times a second.
Followers keep the largest leader-minus-local offset seen in the last 4 s
(network delay only ever makes it smaller), and draw the show at that time.
No pixels travel over the network. Without the leader a follower keeps its
last offset and runs on.

## Files

- `src/wall_render.*` the show, pure C++ (no SDK), timeline at the top.
- `src/main.cpp` spot picker and playback (Scene + dynamic texture), Wi-Fi sync.
- `src/brand_data.hpp` generated by `tools/gen_brand.py` from
  `art/dc8-logo.png` (Devcon logo, Ethereum Foundation, from devcon.org).
- `tools/preview.cpp` renders the whole wall on a computer:

```sh
c++ -std=c++20 -O2 -Isrc tools/preview.cpp src/wall_render.cpp -o /tmp/preview
/tmp/preview 20 | ffmpeg -f rawvideo -pix_fmt rgb24 -s 960x792 -r 20 -i - wall.mp4
```

`kGapX` / `kGapY` in `wall_render.hpp` add the measured screen-to-screen gap
so moving crystals and rings line up across the physical bezels.

## Build

```sh
tools/micropixel package --profile performance --aot-target xtensa guest/apps/devcon-wall
```
