# DevCon Wall

Nine Gotchis in a 3x3 grid play one Devcon 8 India animation together. Each
Gotchi shows its own 296x240 tile of an 888x720 canvas (the Gotchi panel is
296x240 landscape, see `platform/boards/cheeko-gotchi/board_config.hpp`).

## Setup at the booth

No Wi-Fi network or router is needed. The Gotchis talk to each other directly
over ESP-NOW (Peer Radio broadcast, Host firmware with Peer Radio 1.1).

1. Flash every Gotchi with the same Host firmware, then install DevCon Wall.
2. For the steadiest link, leave the Gotchis off Wi-Fi (no saved network):
   then they all meet on channel 1. A Gotchi joined to Wi-Fi stays on its
   router's channel and only hears others on that same channel.
3. Start DevCon Wall on each. First start asks for the spot: 1-9, row by row
   from the top left, as seen from the front.
4. Tap any screen to see its spot map and sync dot for 6 s: green hears other
   Gotchis, amber alone, red radio unavailable. Hold 1.5 s or press BOOT to
   pick the spot again.

## How sync works

Every Gotchi broadcasts its show clock five times a second. Each follows a
reference: spot 5 when heard, otherwise the lowest spot heard (so the wall
keeps playing in step if the centre one is off). Followers keep the largest
reference-minus-local offset seen in the last 4 s (delivery only ever adds
delay) and draw the show at that time. No pixels travel over the air.

## Files

- `src/wall_render.*` the show, pure C++ (no SDK), timeline at the top.
- `src/main.cpp` spot picker and playback (Scene + dynamic texture), ESP-NOW sync.
- `src/brand_data.hpp` generated by `tools/gen_brand.py` from
  `art/dc8-logo.png` (Devcon logo, Ethereum Foundation, from devcon.org).
- `tools/preview.cpp` renders the whole wall on a computer:

```sh
c++ -std=c++20 -O2 -Isrc tools/preview.cpp src/wall_render.cpp -o /tmp/preview
/tmp/preview 20 | ffmpeg -f rawvideo -pix_fmt rgb24 -s 960x792 -r 20 -i - wall.mp4
```

`kGapX` / `kGapY` in `wall_render.hpp` add the measured screen-to-screen gap
so moving crystals and rings line up across the physical bezels.

## Build

tools/micropixel package --profile performance --aot-target xtensa guest/apps/devcon-wall
