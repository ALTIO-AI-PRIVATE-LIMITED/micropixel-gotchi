# Reaction Duel
Two players, one Gotchi. P1 = VOL- (or tap left half), P2 = VOL+ (or tap right half).
Screen goes red ("Wait..."), then green ("GO!"): first to press scores and sees their time in ms.
Press during red and the other player scores. First to 5 wins. Fastest time ever is saved. App ID `cheeko.reaction-duel`.
